#### Agent tools and APIs

- **[ChronoVerify](https://chronoverify.com/)**: Image provenance verification, live in production. A **C2PA Conformant Validator**, one of 6 US-based image validators on the [C2PA Conforming Products List](https://chronoverify.com/c2pa-conformance) (August 2026). Initial signatory of the EU Code of Practice on Transparency of AI-Generated Content (Section 1) alongside Meta, OpenAI, and Google; Content Authenticity Initiative member. Validates Content Credentials against the official trust lists and returns one typed verdict plus a signed report. Verifies provenance; does not claim deepfake detection. Keyless free tier, [MCP server](https://github.com/beeswaxpat/chronoverify-mcp), [agent recipes](https://github.com/beeswaxpat/chronoverify-agent-recipes). ([verify a photo](https://chronoverify.com/) · [API](https://chronoverify.com/method#api))

- **[chronoverify-mcp](https://github.com/beeswaxpat/chronoverify-mcp)**: MCP server on the official registry, npm, Glama, and Smithery. Typed `structuredContent`, honest tool descriptions, works keyless. `npx chronoverify-mcp`

- **[ffmpeg-render-pro](https://www.npmjs.com/package/ffmpeg-render-pro)**: Parallel video renderer for Node.js + FFmpeg. Worker threads split the frame range, GPU encoders auto-detected (NVENC, VideoToolbox, AMF), stream-copy concat with no re-encode. Ships a live dashboard, checkpoints, color grading, audio merge, and an MCP server exposing 7 typed tools.
